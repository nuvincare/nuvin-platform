병원 관리자 회원가입 방법

병원 SaaS 대시보드에 접속해 3단계로 계정을 만들고 병원 정보를 등록합니다.

1
병원 SaaS 대시보드 접속
nuvin2-admin.html 을 브라우저에서 엽니다

대시보드 화면 왼쪽 사이드바 하단에 「병원 등록 / 정보 수정」 버튼이 있습니다. 이 버튼을 클릭하면 3단계 회원가입 모달이 열립니다.

NUVIN SaaS 대시보드
NUVIN SaaS
빈병상 8 / 총 42병상
📊 오늘 대시보드
👥 환자 CRM
📅 예약 캘린더
🏥 병원 등록 / 정보 수정
← 사이드바 하단의 보라색 버튼을 클릭하세요.
이 버튼은 항상 대시보드에 표시됩니다.
기존에 등록된 계정도 이 버튼으로 정보를 수정할 수 있습니다.
2
계정 생성 (STEP 1/3)
아이디·비밀번호·담당자 이름 입력
아이디 (이메일) 필수
병원 또는 담당자의 이메일 주소. 로그인 시 사용됩니다.
예: director@hospital.com
비밀번호 필수
6자 이상. 영문+숫자 조합을 권장합니다.
비밀번호 확인 필수
비밀번호를 한 번 더 입력합니다. 불일치 시 오류가 표시됩니다.
담당자 이름 필수
원장님 또는 담당 직원의 이름. 대시보드에 표시됩니다.
예: 홍길동 원장
모든 필드를 입력한 후 「다음 단계」 버튼을 클릭하세요. 입력값이 올바르지 않으면 오류 메시지가 나타납니다.
3
병원 기본정보 입력 (STEP 2/3)
병원명·주소·유형·전화번호·병상 수
병원명 필수
환자 앱에 표시될 병원의 정확한 명칭.
예: ○○요양병원, □□재활병원
주소 필수
도로명 주소 입력. 카카오맵 핀 위치에 사용됩니다.
예: 서울특별시 강남구 테헤란로 123
병원 유형 필수
선택 가능한 유형: 요양병원 / 재활병원 / 신장투석 클리닉 / 대사질환 클리닉 / 종합병원 / 기타
전화번호 선택
환자 가족이 전화 버튼 클릭 시 연결될 번호.
예: 02-1234-5678
총 병상 수 선택
병원 전체 병상 수. 빈병상 관리의 기준값이 됩니다.
주소를 정확히 입력해야 카카오맵에서 올바른 위치에 핀이 표시됩니다. 도로명 주소를 권장합니다.
4
서비스 설정 (STEP 3/3)
진료 카테고리 선택 · 병원 소개 작성
진료 카테고리 복수선택
🎗️ 암수술후 요양  |  🧠 뇌수술후 요양  |  🩸 24시간 신장투석
🩺 대사질환 외래  |  💉 신장투석
환자 앱 검색 필터에 반영됩니다. 복수 선택 가능.
병원 소개 선택
병원 특장점, 의료진 소개, 시설 안내 등을 입력합니다.
예: "24시간 간호 인력 배치, 1인실 완비, 암 환자 전문 영양식 제공"
「등록 완료」 버튼 클릭 시 즉시 환자 앱 검색 목록에 노출됩니다.
등록 후 사이드바의 병원명과 담당자 이름이 입력한 정보로 자동 업데이트됩니다.

🗺️ KAKAO MAP

카카오맵 API 연동 방법

카카오맵을 연동하면 환자 가족이 병원 위치를 실제 지도에서 확인하고 경로를 조회할 수 있습니다.

1
카카오 개발자 계정 생성
developers.kakao.com 접속 → 카카오 계정으로 로그인 → 「내 애플리케이션」 클릭
2
애플리케이션 등록
「애플리케이션 추가하기」 → 앱 이름 입력 (예: NUVIN병원) → 회사명 입력 → 저장
3
플랫폼(도메인) 등록
앱 상세 → 「플랫폼」 → Web → 「사이트 도메인 추가」 → 운영 중인 도메인 입력 (예: https://nuvin.kr) → 저장
4
JavaScript 앱 키 복사
앱 상세 → 「앱 키」 탭 → JavaScript 키 복사 (32자리 영문+숫자)
5
NUVIN에 키 입력
nuvin2-search.html 열기 → 상단 지도 아이콘 클릭 또는 배너 클릭 → 「카카오맵 API 키 설정」 모달 → JavaScript 앱 키 입력 → 「저장 및 활성화」
✅ 키 저장 후 즉시 실제 카카오맵으로 전환됩니다.
/* nuvin2-search.html 소스코드 수정 방법 (대안) */ /* 파일 상단 주석 처리된 스크립트 태그를 활성화하세요: */ <!-- 아래 주석을 제거하고 YOUR_APP_KEY를 실제 키로 교체 --> <script type="text/javascript" src="//dapi.kakao.com/v2/maps/sdk.js?appkey=YOUR_JAVASCRIPT_APP_KEY&libraries=services"> </script>
무료 한도: 지도 API 30만 호출/일, 로컬(장소 검색) API 10만 호출/일. 대부분의 병원 규모에서 무료로 충분합니다.
🏥 HIRA API

건강보험심사평가원(심평원) 공공데이터 API

심평원 오픈 API를 연동하면 공식 병원 정보(명칭·주소·진료과목)를 자동으로 불러올 수 있습니다.

CORS 제한 안내: 심평원 API는 브라우저에서 직접 호출 시 CORS 오류가 발생합니다. 실제 운영 시에는 NUVIN 서버(백엔드 프록시)를 통해 처리됩니다. 현재는 API 키를 미리 등록해두면 서버 연동 시 자동으로 동작합니다.
1
공공데이터포털 가입
data.go.kr 접속 → 회원가입 또는 로그인
2
병원정보서비스 검색
검색창에 「건강보험심사평가원_병원정보서비스」 검색 → 「오픈API」 탭 클릭 → 「활용신청」 버튼
3
활용 목적 작성 후 신청
활용목적 선택 → 상세 설명 입력 (예: 요양병원 정보 표시 서비스) → 신청 제출. 승인까지 1~2일 소요.
4
인증키 확인
마이페이지 → 「오픈API 신청 현황」 → 승인 완료 후 일반 인증키(Encoding) 복사
5
NUVIN에 키 입력
nuvin2-search.html의 지도 API 키 설정 모달 하단 「심평원 서비스키」 입력란에 붙여넣기 → 저장. 승인된 API는 서버 연동 후 자동으로 병원 데이터를 가져옵니다.
