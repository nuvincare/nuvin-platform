서버 이전 PWA / 앱 DB 구조

⚠️ 왜 국내 서버가 필요한가요?

현재 누빈 데이터는 Genspark Inc.(미국) 서버에 저장됩니다. 질환명 등 민감정보는 「개인정보 보호법」 제17조·제18조에 따라 국내 서버 또는 보호 조치 후 이전이 권장됩니다. 서비스 본격화 전 국내 클라우드로 이전하면 법적 안정성이 높아집니다.

국내 클라우드 서비스 비교
서비스 추천 플랜 월 비용(소규모) 특징
AWS 서울 (ap-northeast-2) RDS MySQL + EC2 또는 Lambda 약 3~8만원 가장 안정적, 글로벌 표준
NCP (네이버 클라우드) Cloud DB for MySQL + Server 약 3~6만원 국내 지원 우수, 한국어 문서
KT Cloud Object Storage + VM 약 2~5만원 KT 인프라 기반, 중소기업 친화
Cafe24 호스팅 MySQL + 웹호스팅 약 1~3만원 가장 간단, 기능 제한 있음

✅ 누빈 초기 단계 추천: NCP (네이버 클라우드)

한국어 지원이 좋고, 스타트업 크레딧 프로그램 신청 가능(최대 3백만원). MySQL + 웹서버 세트로 간단히 시작 가능.

단계별 이전 계획 (4주 로드맵)
1

준비 단계 (1주차) — 데이터 내보내기

현재 Genspark Tables API에서 모든 데이터를 JSON으로 내보냅니다.

JavaScript (브라우저 콘솔)
// 관리자 페이지 콘솔에서 실행 fetch('tables/nuvin_users?limit=9999') .then(r => r.json()) .then(d => { const blob = new Blob([JSON.stringify(d.data, null, 2)], {type:'application/json'}); const a = document.createElement('a'); a.href = URL.createObjectURL(blob); a.download = 'nuvin_users_backup.json'; a.click(); });
  • 백업 파일을 안전한 곳에 보관
  • 민감정보 포함이므로 암호화 압축 권장 (7-Zip AES-256)
2

서버 준비 (1~2주차) — NCP 또는 AWS 설정

국내 클라우드에 서버와 DB를 생성합니다.

  • NCP: Console → Cloud DB for MySQL → 생성 클릭, 서울 리전 선택
  • DB명: nuvin_db / 사용자: nuvin_admin
  • 방화벽에서 포트 3306은 서버 내부만 허용 (외부 차단)
  • 백엔드 API 서버: Node.js Express 또는 Python FastAPI 추천
MySQL — 테이블 생성 SQL
CREATE TABLE nuvin_users ( id VARCHAR(36) PRIMARY KEY, name VARCHAR(100) NOT NULL, email VARCHAR(200), phone VARCHAR(20), primary_disease VARCHAR(50), -- 'cancer'|'brain'|'metabolic' cancer_type VARCHAR(100), brain_type VARCHAR(100), metabolic_type VARCHAR(100), main_issues JSON, -- 배열 저장 step_completed INT DEFAULT 0, agree_medical TINYINT(1) DEFAULT 0, agree_sensitive TINYINT(1) DEFAULT 0, agree_marketing TINYINT(1) DEFAULT 0, login_type VARCHAR(20), created_at DATETIME DEFAULT CURRENT_TIMESTAMP, updated_at DATETIME ON UPDATE CURRENT_TIMESTAMP );
3

데이터 마이그레이션 (2~3주차) — 데이터 이전

백업한 JSON을 MySQL에 삽입합니다.

Node.js — JSON → MySQL 삽입 스크립트
const mysql = require('mysql2/promise'); const data = require('./nuvin_users_backup.json'); const conn = await mysql.createConnection({ host: 'your-ncp-db-host', user: 'nuvin_admin', password: 'YOUR_DB_PW', database: 'nuvin_db' }); for (const user of data) { await conn.execute( `INSERT INTO nuvin_users (id,name,email,phone,primary_disease,main_issues, agree_medical,agree_sensitive,agree_marketing,created_at) VALUES (?,?,?,?,?,?,?,?,?,?)`, [user.id, user.name, user.email, user.phone||null, user.primary_disease, JSON.stringify(user.main_issues||[]), user.agree_medical?1:0, user.agree_sensitive?1:0, user.agree_marketing?1:0, new Date(user.created_at).toISOString().slice(0,19).replace('T',' ')] ); } console.log('✅ 마이그레이션 완료!');
4

API 교체 (3~4주차) — Genspark API → 자체 API

누빈 프론트엔드의 fetch('tables/nuvin_users'...)를 자체 API로 교체합니다.

변경 전 (Genspark)
fetch('tables/nuvin_users', { method:'POST', ... })
변경 후 (자체 서버)
fetch('https://api.nuvin.kr/users', { method:'POST', ... })
  • CORS 설정 필수: Access-Control-Allow-Origin: https://nuvin.kr
  • HTTPS 인증서 발급: Let's Encrypt 무료 SSL 적용
  • 모든 API 엔드포인트를 환경 변수로 관리 추천
5

보안 강화 (4주차 이후)

  • 민감정보(질환명) AES-256 컬럼 암호화 적용
  • DB 접근 로그 CloudTrail/Activity 기록 활성화
  • 정기 자동 백업 설정 (매일 새벽 3시)
  • 개인정보 처리 위탁 계약서 작성 (NCP 또는 AWS와)

🏆 누빈에게 추천하는 방식은?

현재 단계에서는 PWA (Progressive Web App)를 강력 추천합니다. 앱스토어 없이 바로 아이콘 설치가 가능하고 개발 비용이 거의 없습니다.

누빈 PWA 즉시 적용 방법 (3단계)
1

manifest.json 생성 (아이콘·앱 이름 설정)

manifest.json 핵심 내용

Service Worker 등록 (오프라인 지원)

service-worker.js가 이 프로젝트에 포함되어 있습니다. ✅

  • 오프라인 상태에서도 캐시된 페이지 열람 가능
  • 접속 속도 향상 (캐시 활용)
3

사용자가 설치하는 방법

Android (크롬):

  • 누빈 사이트 접속 → 하단에 "홈 화면에 추가" 배너 자동 표시
  • 또는 브라우저 우상단 ⋮ → "홈 화면에 추가" 탭
  • 설치 후 홈 화면에 누빈 아이콘이 앱처럼 표시됨

iPhone (iOS 사파리):

  • 사파리로 접속 → 하단 공유 버튼(□↑) → "홈 화면에 추가"
  • iOS 16.4 이상에서 푸시 알림도 지원
앱패키징이 필요해지는 시점
  • 📊 월간 활성 사용자 1,000명 이상 — 앱스토어 노출로 추가 성장 필요 시
  • 💬 카카오/네이버 실제 소셜 로그인 연동 시 (SDK 네이티브 버전 필요)
  • 🔔 iOS 16.4 이전 iPhone 사용자에게 푸시 알림 필요 시
  • 📁 로컬 파일 저장 (가이드북 PDF 저장 등) 기능 추가 시
  • 🏥 의료기관 연동 API 또는 EMR 시스템 연동 시

📌 앱패키징 추천 시점

사용자 1,000명 달성 → PWA 유지, 앱스토어 등록을 위해 TWA(Trusted Web Activity) 방식으로 기존 웹을 그대로 앱화하면 추가 개발 없이 플레이스토어 등록 가능.

✅ DB 이전 용이성 평가: 매우 쉬움

현재 누빈 DB는 단일 테이블(nuvin_users) 구조이며, 모든 필드가 표준 데이터 타입으로 구성되어 있어 어떤 관계형 DB(MySQL, PostgreSQL)나 NoSQL(MongoDB, Firestore)로도 손쉽게 이전 가능합니다.

DB 이전 호환성 평가
✓

단일 테이블 → 복잡도 낮음

현재 nuvin_users 테이블 하나만 존재하여 조인이나 외래키 이슈 없이 단순 데이터 복사(INSERT)만으로 이전 완료 가능합니다.

✓

REST API 방식 → 교체 용이

프론트엔드에서 fetch('tables/nuvin_users') 패턴이 일관되게 사용되므로, 엔드포인트 URL만 변경하면 코드 수정이 최소화됩니다.

✓

JSON 내보내기 지원

Genspark Tables API가 JSON 형태로 데이터를 반환하여 별도 변환 없이 이전 스크립트에 직접 사용 가능합니다.

!

main_issues 배열 필드 주의

MySQL에서는 JSON 타입 컬럼으로 저장하면 됩니다. PostgreSQL은 JSONB 타입 사용. MongoDB는 그대로 배열로 저장 가능합니다.
