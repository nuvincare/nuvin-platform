② 무료 가입 · 30초 완성 버튼 클릭 → 이름·이메일 입력
③ 가입 완료 후 마이누빈 탭에 내 정보가 표시됩니다
④ 이미 가입했다면: "로그인하기" 클릭 → 가입 이메일 입력

① 화면 우측 하단 보라색 💬 버튼 클릭
② 비로그인 상태면 자동으로 가입 안내가 나옵니다
③ 로그인 후: 🏥 병원 / 🤝 멘토 / 📢 공지 탭 이용
④ 마이누빈 탭에서도 "누빈 메신저 열기" 버튼으로 접근 가능
